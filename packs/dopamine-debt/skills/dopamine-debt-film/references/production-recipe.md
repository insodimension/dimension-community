# Production recipe: how the Altman RAM roast was made (2026-11-03 → 11-04)

The reference run for a Dry Run explainer roast, from a one-line brief to a sealed render Inso approved ("there were no mistakes"). Production folder: `altman-ram-roast/` among the productions (`dd.home.PRODUCTIONS`). This file names every stage, the tool used, what it wrote, and the trap met. SKILL.md is the order of work; this is the worked example.

**Source note.** Stages 1–6 come from the files they left behind (dated headers, logs, asset records). The session that ran them was compacted, so which skill files it loaded is not on record. It did **not** load this skill (gotchas, 2026-11-04). Stages 7–11 were observed directly.

## Infrastructure used

- **Plugins and services:** the Video space media library (memes); the `media` generation provider (ElevenLabs voice and music); HyperFrames CLI 0.8.217 (composition, snapshot and render engine).
- **Session tools:** `task` (researchers, persona coders, blind loggers), `hub` (render service), `bash`, `read`/`edit`/`write`, `eval` with `completion` (judges), `present`, `room://` messages (coordination with the Anthropic film session and the library owner), `retain`.
- **Local binaries:** ffmpeg/ffprobe, yt-dlp, faster-whisper (CPU), PyMuPDF, numpy, librosa, resvg.
- **Shared code:** `DD/framework/kit/` (the film builder and mix), `DD/framework/g11.py`, `overlays.py`, `quiet.py`, `layout.py`; `DD/taste.json`; `DD/dd/gate.py` (G1–G10, not run for this film: no persona ledger).
