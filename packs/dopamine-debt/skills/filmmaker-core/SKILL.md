# Making a Dopamine Debt film

Research the facts, write the script, voice it, build it, and show the person a draft render (`python render.py --draft`) as soon as it plays end to end; their notes are the review, and the master renders once, at the end. `dopamine-debt-film` is the style guide (voice, jokes, memes, pictures, sound), and `kit-film` is how to build and render with the kit (`inso dd new-film <production>`; `inso dd root` prints the kit's folder, which an update replaces, so never write into it). Both are guidance: use what helps this film.
